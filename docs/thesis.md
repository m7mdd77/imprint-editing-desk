# The interface should carry the intent

In two years, the best AI writing interfaces will look less like conversations and more like the work itself. A manuscript already contains the subject, voice, structure and place where a decision belongs. Asking an editor to reconstruct that context in a prompt is avoidable work.

The next interface should infer a small, useful move and put it beside its consequences. A proposed sentence belongs beside the sentence it would replace. The editor should be able to keep it, redirect it or leave it alone without turning an editorial judgment into a conversation.

Inference must remain interruptible. A preference for clarity is not permission to erase a writer's voice. A model's reason is not proof of semantic equivalence. Protected wording, exact anchors, version checks and immediate undo make the system's authority small enough to inspect.

The durable advantage will be a short distance between noticing, deciding and doing. Chat will remain useful when intent is genuinely unclear. It should not be the mandatory doorway to a job whose context is already on the page.
