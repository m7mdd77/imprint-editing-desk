# When the margin note is wrong

There are two recovery paths.

**An editorial wrong turn:** the suggestion may flatten the author's voice, even if its quote and numbers are valid. Keep the original leaves the document byte-for-byte unchanged and excludes that span from the next reading. “Wrong direction? Keep the voice” also changes the context and initiates a new genuine inference. This is an editor's judgment about a draft, not a claim that the model can score its own correctness. If an edit was already accepted, Undo restores the exact prior text without a provider call.

**An invalid or stale patch:** injected test responses target the protected opening, quote nonexistent or duplicate passages, change a number, carry invented approval/tool fields or arrive against changed text/version. The shared validator refuses them before application. The public transport separately refuses unauthenticated claims, cross-origin/CSRF requests, publishing commands and late/repeated completions. Timed-out writing is removed from the queue. Tests use model doubles and do not constitute provider evidence.

The actual first local browser call could not finish under Windows sandbox restrictions. The UI showed an unavailable state and made no document change. After the supported client was run with the needed process permission, genuine DeepSeek produced an anchored revision of Austen's second paragraph. The browser applied it, then Undo restored the original text exactly. No canned response was substituted for the failed call.

Further actual provider and browser receipts are recorded separately under evidence/. This prototype does not claim automatic semantic correctness, universal prompt-injection immunity or provider retention control.
